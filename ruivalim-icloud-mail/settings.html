The app-specific password is stored encrypted by Cindy on this device

Make sure two-factor authentication is turned on for your Apple Account, then go to the Apple Account website and generate a password under "Sign-In and Security > App-Specific Passwords". Do not enter your Apple Account password here.

The app-specific password never reaches Agent arguments or the plugin's main.js. Cindy hands it to the plugin Worker only while running a mail request. Mail operations use short-lived connections and close IMAP/SMTP as soon as they finish.
